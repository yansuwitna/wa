Cara Menggunakan API (Untuk Client)

Kirimkan POST request ke /api/send dengan payload JSON berikut:

{
    "no_hp": "6281234567890",
    "isi": "Pesan informasi dari sistem",
    "token": "TOKEN_CLIENT",
    "secret": "SECRET_CLIENT"
}

Pesan akan masuk ke antrean database dan cron job akan memprosesnya dalam 0-5 menit ke depan dengan jeda acak (anti-spam).
